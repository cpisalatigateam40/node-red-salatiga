GIT-REPO
========
A. TUTORIAL IMPORT MANUAL
  1. Buka file flows.json
  2. Copy isinya
  3. Buka Node-red
  4. Click kanan atas, pilih import
  5. Paste disana, klik copy
  6. Jika muncul notifikasi, import copy

B. TUTORIAL IMPORT OTOMATIS DAN TER INTEGRASI DENGAN GITHUB (GIT CLONE)
  1. Buka Node-red
  2. Click kanan atas, project -> new
  3. Pilih Clone Repository
  4. Masukan project name
  5. Git Repository URL : git@github.com:cpisalatigateam40/node-red-salatiga.git
  6. Pilih Clone Repository
